QUEST

Is this 4-digit number perfect?

A number is perfect when it equals the sum of its divisors smaller than itself. Example: 6 = 1 + 2 + 3. Print True if n (1000 to 9999) is perfect, otherwise False. The boss changes n each round, so keep that first line.

GUIDE

How to spot a perfect number

  1. List every divisor of n that is smaller than n (numbers that divide it with nothing left over).
  2. Add those divisors together.
  3. If the sum equals n, it is perfect.

Example: 28 → 1 + 2 + 4 + 7 + 14 = 28 ✓. But 12 → 1 + 2 + 3 + 4 + 6 = 16 ✗.

Python plan
1) total = 0 · 2) loop i from 1 to n−1 · 3) if n % i == 0, add i to total · 4) print total == n

Fun fact: the only perfect number with 4 digits is 8128.

QUEST · PHASE 2

Catch the lightning

The Storm Wyrm shouts how many bolts it will throw, then the power of each bolt, one number at a time. Your code must listen with input(), loop over the bolts, and print the total power.

Example
The Wyrm shouts 3, 4, 5, 6. That is 3 bolts with power 4, 5 and 6, so your code prints 15.
GUIDE

How to listen and loop

  1. Read the first number with n = int(input()). It tells you how many bolts are coming.
  2. Start a counter: total = 0.
  3. Repeat n times with for i in range(n):.
  4. Inside the loop, read one bolt with int(input()) and add it to total.
  5. After the loop, print(total).

Good to know: input() always gives you text, so wrap it in int() to get a number.
